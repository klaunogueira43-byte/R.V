R.V Radar de Vendas  -  agora ligado ao Supabase

COMO FUNCIONA
- Os imóveis, os textos do site e os perfis dos corretores ficam no Supabase (banco de dados).
- As fotos ficam no Supabase Storage (bucket "imoveis-fotos").
- O corretor entra pela engrenagem > "Área do corretor" com e-mail e senha.
- Tudo que o corretor salva vai direto para o banco: o site dos clientes mostra a mudança na hora
  (quem está com a página aberta vê atualizar sozinho). Não precisa mais exportar nem subir arquivo.

IMPORTAR PASTA (modo corretor > "Importar pasta")
Monte uma pasta com UMA SUBPASTA POR IMÓVEL. Dentro de cada uma: as fotos + um arquivo info.txt.
  Meus imoveis/
    Apto Jardins/   info.txt, capa.jpg, sala.jpg, 2.jpg, 10.jpg ...
    Studio Pinheiros/   info.txt, 01.jpg, 02.jpg ...
Escolha a pasta (computador) ou um .zip dela (funciona no celular). O sistema separa cada imóvel,
lê o info.txt, ordena as fotos (a "capa" vem primeiro; o resto em ordem natural: 2 antes de 10),
mostra uma PRÉVIA editável e só salva depois que você confirmar. Imóvel já cadastrado (mesmo título
e bairro) vem desmarcado. Fotos HEIC (iPhone) não são lidas: converta para JPG.
No info.txt (um por linha; só Título, Bairro e Preço são obrigatórios):
  Título: ...   Bairro: ...   Preço: 890000 (aceita R$ 890.000,00 / 890 mil / 1,2 milhão)
  Quartos: 3    Banheiros: 2  Vagas: 2   Área: 105   Situação: venda | reservado | vendido
  Corretor: maria (id ou nome)   Descrição: texto (pode ter várias linhas)
Também vale um info.json com os mesmos nomes. Há um botão para baixar um modelo pronto.

IMPORTAR A PASTA THAIS IMOB (cidade > construtora)
Escolha a pasta "Thais Imob" (ou só uma cidade, ou o .zip). Cada pasta de construtora dentro de uma cidade vira UM imóvel:
  Thais Imob/Arujá/CAC Verdi/ imagens, implantação, plantas, localização, book de entrega, enunciado.txt
- Fotos entram nesta ordem: imagens (capa primeiro), implantação, plantas, localização.
- O "enunciado" (txt) fornece os dados; com linhas "Preço: ...", "Quartos: ..." ele preenche os campos, e texto solto vira descrição.
- A cidade vai junto no bairro (ex: "Centro - Arujá"); se não houver bairro, usa só a cidade.
- Pasta TikTok/<cidade>/<imóvel>: não cria imóvel; se o nome bater com uma construtora, o info dela completa os dados
  (ex: "Disponível: não" marca como vendido).
- PDFs (book de entrega) ainda não são importados.

NOVO CORRETOR
1. Supabase > Authentication > Users > Add user (e-mail + senha, marque "Auto Confirm User").
2. Vincular o usuário à tabela de acesso (SQL Editor):
   update public.corretores_acesso a set user_id = u.id
   from auth.users u where lower(u.email) = lower(a.email) and a.user_id is null;
   (antes, a coluna "email" da linha do corretor em corretores_acesso precisa estar preenchida)

IMPORTANTE
- Em Authentication > Sign In / Providers, desligue "Allow new users to sign up".
- Nunca coloque a chave "service_role"/"secret" neste site. A chave publishable em config.js é pública por natureza.
- O arquivo imoveis.json é só um backup dos dados antigos; o site não usa mais.
